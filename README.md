## 01 — Field notes: The Platypus Principle

When it was first described, naturalists assumed the specimen was a hoax—fur stitched to a duck's bill. It wasn't. An egg-laying mammal with a sensory bill, otter feet, a beaver's tail, and a venomous spur was simply true, assembled from parts that evolved to solve entirely different problems.

We build software the same way. The best fix for a frontend problem sometimes comes from compilers, and a data problem sometimes bends toward biology. We do not defend our stack's coherence—we defend whether it works.

---

## 02 — Identifying marks: Four traits

<details>
<summary><strong>Electroreception</strong></summary>
The bill senses electric fields in murky water, hunting by feel instead of sight. We ship the same way—instrumented early, watching for signal in the noise before we watch for opinions.
</details>

<details>
<summary><strong>An unusual bill</strong></summary>
The shape exists because the problem demanded it, not because it matched anything else in nature. We would rather hand-fit a tool to the actual shape of a problem than reach for the nearest framework.
</details>

<details>
<summary><strong>A venomous spur</strong></summary>
Rarely used, and unmistakable when it is. Most of what we build is quiet and load-bearing—the occasional sharp opinion is reserved for the decisions that are hard to reverse.
</details>

<details>
<summary><strong>An egg-laying mammal</strong></summary>
It broke the category before the category existed. We are less interested in which box a project fits than in whether it is the right answer, taxonomy be damned.
</details>
